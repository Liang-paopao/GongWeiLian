# 工维联本机演示指南

1. 已准备项目 Python 环境后，运行 `start_stage2.cmd`。等待四个服务健康检查通过，再打开输出的地址，默认是 `http://127.0.0.1:18010/`。端口可通过 `GONGWEI_STAGE2_*_PORT` 配置。
2. 在对话框描述设备、日期、开始时间、预计时长和异常情况。Leader 会询问缺少的字段，补充完整后显示待确认方案。
3. 查看人员、时间和库存方案，确认后创建工单。重复确认受幂等保护；修改安排时先发送新的需求并查看返回方案。
4. 可选地在“声音辅助”上传 WAV 并检测。页面仅显示“未发现明显异常”或“疑似异常”，不会自动创建任务或工单。需要检查时通过对话描述情况，再确认检查方案。后端另保留 `/api/audio/confirm` 人工确认接口，当前页面未提供该接口的按钮。
5. 在工单页查看详情，使用“标记处理中”“标记已完成”或“取消工单”。工单完成、失败或取消时，本次预留的人员、工具和配件都会自动归还；重复操作不会重复增加库存。在协作记录页查看当前任务的时间线与调用记录。
6. 在“资源与审计 → 工具与配件”中，可用每行的“− / ＋”按钮手动调整演示库存。调整同时更新可用量和总量，并写入审计事件；不能把数量调到 0 以下，也不能减少已被活动预留占用的库存。
7. 运行 `stop_stage2.cmd` 停止由当前启动器记录且身份匹配的项目进程。它不会按端口强制结束未知进程。此前用旧脚本启动、没有记录的服务应从原终端关闭。
8. `GONGWEI_LOG_DIR` 可指定日志和启动器进程记录目录，启动和停止时应保持一致。测试使用临时数据库；备份和保护 `data/stage2.db`，不要把生产数据放入演示包。

页面和接口均标记模拟业务数据，不能作为梧桐平台验证或真实工厂收益证明。

本页说明本机演示操作。当前平台状态见 `../STATUS.md`；本轮维护检查与限制见 `../reports/final-maintenance-audit/`。
