# 评审演示场景

| 场景 | 操作 | 预期证据 |
|---|---|---|
| 手动建单 | 完整填写并确认 | 一张工单、三条资源预留、时间线 |
| 缺参 | 只填水泵 | `awaiting_input` 和字段名 |
| 重复确认 | 同一 Idempotency-Key 再提交 | 原工单和 `idempotent=true` |
| 资源变化 | 方案后移除技能再重排 | 方案版本递增、`plan_replanned` |
| 工单失败 | 使用测试脚本注入失败 | 资源释放、补偿审计 |
| 服务恢复 | 在 confirming 阶段重启 Leader | 预留释放或工单状态对账 |
| 声音辅助 | 上传 WAV，确认后生成方案 | 安全 verdict、人工确认门槛 |
