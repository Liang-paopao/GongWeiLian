# 工维联前端四视图重构设计

## 范围

本次只修改现有项目的 `web/` 前端资源，不修改业务逻辑、数据库结构、后端 API、AIC、MQ 或证书配置。页面继续使用现有 FastAPI 服务和 SQLite 产生的真实数据，`platform_verified=false` 的边界在界面上保留。

## 视图与数据流

- **协作**：通过 `/api/conversations` 创建会话，通过 `/api/conversations/{session_id}/messages` 进行多轮对话；任务计划、状态和协作节点由返回数据与 `/api/tasks/{task_id}/trace` 补全。
- **方案确认**：在有计划时显示真实设备、时间、时长、人员和库存；确认调用 `/api/tasks/{task_id}/confirm`，修改调用 `/api/tasks/{task_id}/revise`，取消调用 `/api/tasks/{task_id}/cancel`。
- **工单中心**：读取 `/api/work-orders`，使用现有取消和状态更新接口；列表、筛选和详情都绑定返回对象，不写入示例编号或日期。
- **资源与审计**：读取 `/api/bootstrap` 的人员和库存，读取任务追踪、`/api/audit` 与 `/api/aip-calls`；库存行提供受后端校验的“− / ＋”手动调整，写入审计事件；没有真实记录时显示说明性空状态。

视图通过 URL hash 切换，保持同一页面、同一会话状态和事件绑定，不复制业务实现。页面刷新时恢复视图并重新加载可用的真实列表数据。

## 信息层级

顶部只展示产品名、服务状态、运行模式和数据边界。主内容优先展示可执行状态、下一步动作和业务事实。`sessionId`、`taskId`、`messageId`、AIC、原始 JSON 等技术字段放入默认折叠的“技术详情”。声音辅助仍是可选抽屉，不影响文字流程。

## 视觉与响应式

延续参考图的深色工作台顶部、白色内容面板和青绿色操作色，避免渐变、装饰性动画和无数据指标。三栏页面在宽屏展示对话、计划、当前任务；中等宽度改为两列；窄屏单列。所有控件有焦点、禁用、处理中、错误和空状态；尊重 `prefers-reduced-motion`。

## 验收

1. 现有多轮对话、缺参询问、方案确认、幂等创建和取消流程可在浏览器完成。
2. 四个视图均由真实 API 数据驱动，空数据不伪造示例内容。
3. 1366×768、1440×900、1920×1080 可读且不横向溢出。
4. 全部现有 Python 回归测试保持通过，浏览器逐项点击测试记录在交付报告中。
